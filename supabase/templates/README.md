# Modelos de e-mail do Supabase Auth

Cole em Supabase → Authentication → Emails → Templates.

| Aba | Arquivo | Assunto |
|---|---|---|
| Confirm signup | confirmacao.html | Confirme seu e-mail · Rotta 365 |
| Magic Link | link-magico.html | Seu link de acesso · Rotta 365 |
| Reset Password | recuperar-senha.html | Redefina sua senha · Rotta 365 |
| Change Email Address | troca-email.html | Confirme seu novo e-mail · Rotta 365 |

O envio sai pelo SMTP do Resend (`nao-responda@rotta365.com.br`).
